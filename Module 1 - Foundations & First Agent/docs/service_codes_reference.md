# Service Request & Error Code Reference  (Policy Ref: POL-SRV-2024-08)

## Service Request Codes
- SR-KYC — update KYC / re-verification; TAT 3 working days.
- SR-CHQBK — new cheque book request; delivered in 7 working days.
- SR-STOP — stop-payment instruction on a cheque; fee 100 per instrument.
- SR-DISPUTE — raise a transaction dispute / chargeback; provisional credit in 10 days.
- SR-ADDR — change of registered address; requires fresh address proof.

## ATM / Card Error Codes
- E-4021 — insufficient funds at withdrawal.
- E-5100 — card hotlisted; issue a replacement (fee waived once per year).
- E-3300 — wrong PIN; card retained after 3 attempts at some ATMs.
- E-9001 — ATM cash-out / hardware fault; no debit occurs, retry elsewhere.

## Net-Banking Error Codes
- NB-2200 — session expired; re-login required.
- NB-4400 — beneficiary not yet activated (30-minute cooling period for new payees).

## Escalation
Unresolved complaints after 7 days escalate to the Nodal Officer; after 30 days, to the
Banking Ombudsman. Fraud hotline: 1-800-BANK-911 (24x7).
